# Instruciones
## Requirementos
- python
- pyhton3-pip


## Compilar
```sh
git clone git@github.com:T4C30/SteamToGog.git
cd ./SteamToGog
./compilar.sh
```

## Ejecutar
```sh
git clone git@github.com:T4C30/SteamToGog.git
cd ./SteamToGog
python -m venv .venv
# En terminal bash
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```
